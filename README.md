# Ascendia Investments Co — Investor Relations & Pitch Deck Suite

Welcome to the institutional capital raising and Investor Relations (IR) suite for **Ascendia Investments Co**.

---

## 📦 What's Included in This Suite

1. **`index.html`** — **Interactive Pitch Deck Web Application**
   - High-contrast, luxury institutional dark-navy & gold presentation.
   - Built-in **IR Speaker Notes & Talking Points** side drawer (toggle with key `N` or the bottom control bar).
   - **Interactive LP Return Simulator & Waterfall Calculator** (toggle with key `C`).
   - **Slide Overview Grid** for jumping directly to any topic (toggle with key `O`).
   - Print-to-PDF ready: Press `Ctrl+P` or click the printer icon to generate clean landscape 16:9 slides.

2. **`IR_PITCH_PLAYBOOK.md`** — **Complete Master Script & Objection Handling Playbook**
   - Slide-by-slide verbatim speech tracks with tone cues and timing.
   - Top 10 institutional allocator objection responses (waterfall mechanics, valuations, track record verification, credit risk, macro rates).
   - Multi-touch email follow-up templates for prospective LPs.

3. **`EXECUTIVE_TEASER_ONE_PAGER.md`** — **Executive Summary & Fund Terms Sheet**
   - Formatted for pre-read emails, introduction packets, and quick IC review.

4. **`LP_VIRTUAL_DATA_ROOM_CHECKLIST.md`** — **Due Diligence Virtual Data Room (VDR) Index**
   - Complete 6-section institutional index for LP onboarding.

## 🚀 How to Run and Present

### Option A: Open Directly in Any Web Browser
Simply double-click `index.html` or right-click and choose **Open with Google Chrome / Microsoft Edge / Brave**.

### Option B: Host Locally via HTTP Server (Optional)
If you prefer running a local server:
```powershell
# In PowerShell:
npx serve .
# Or with Python:
python -m http.server 8000
```
Then open `http://localhost:8000` in your browser.

## ⌨️ Presentation Keyboard Shortcuts

| Key | Action |
|:---|:---|
| **`→` / `Space` / `PageDown`** | Next Slide |
| **`←` / `PageUp`** | Previous Slide |
| **`N`** | Toggle **IR Speaker Script & Talking Points** Drawer |
| **`C`** | Open / Close **LP Returns & Distribution Calculator** |
| **`O`** | Open / Close **Slide Overview Grid** |
| **`P` / `Ctrl+P`** | Export / Print Deck to PDF (Landscape) |
| **`Esc`** | Close all drawers and modals |

---

## 🖨️ Exporting to PDF
1. Open `index.html` in Chrome or Edge.
2. Press `Ctrl + P` (or click the printer icon on the bottom bar).
3. Set **Destination** to `Save as PDF`.
4. Set **Layout** to `Landscape`.
5. Under **More Settings**, enable `Background graphics` and set **Margins** to `None`.
6. Click **Save**.
